# sophia.plant
sophia.plant é um portfólio interativo de Engenharia de Software (PUC Minas) com tema de jardim. Os projetos formam uma linha do tempo onde a maturidade de cada software é representada por sementes, brotos ou flores. Inclui um Jardim de Visitantes interativo (Supabase), formulário (EmailJS), i18n nativo (PT/EN) e deploy na Vercel.
